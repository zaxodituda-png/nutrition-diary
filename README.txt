ДНЕВНИК ПИТАНИЯ — локальная версия 1

1. Распакуйте архив.
2. Откройте index.html двойным щелчком в браузере.
3. Выберите 7 ноября 2026: запись из PDF уже внесена.
4. Нажмите «Редактировать день», чтобы изменить запись или добавить новый день.
5. Вставьте ссылку на публичную активность Strava (https://www.strava.com/activities/123456789).

Важно:
- Данные хранятся в localStorage браузера. В другом браузере или на другом устройстве их не будет.
- Очистка данных браузера может удалить записи. Не используйте эту версию как единственную копию дневника.
- Это локальный прототип, не готовый публичный сайт. Для доступа нутрициолога и безопасного редактирования понадобится серверное хранилище и авторизация.
- Встраивание Strava зависит от публичной доступности активности и политики Strava.
- Данные за 07.11.2026 взяты из предоставленного PDF. Расход и калорийность — оценки.
